Essa é a tela de contagem de estoque, usada quando a equipe precisa conferir na prática se o que está anotado no sistema bate com o que realmente existe no depósito. Aqui fica a lista de todas as contagens já feitas ou em andamento.

Cada linha mostra quando a contagem começou, se ainda está aberta ou já foi fechada, e quem é o responsável por ela. A partir daqui dá para abrir uma contagem específica e ver os detalhes de cada item conferido.

O ponto forte dessa etapa é que, quando a contagem é fechada, qualquer diferença encontrada entre o que estava registrado e o que foi contado vira um ajuste automático no estoque, sem trabalho manual extra. Essa tela foi criada com uma empresa real de tecnologia para deixar o inventário periódico simples e confiável.
