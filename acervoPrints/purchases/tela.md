Essa é a tela onde ficam todos os pedidos de compra feitos para os fornecedores. Cada linha da lista mostra o código do pedido, o fornecedor, o valor total, a data prevista de chegada e em que etapa o pedido está, se ainda é um rascunho, se já foi enviado ou se já foi recebido.

A partir dela dá para abrir um pedido já existente e acompanhar os detalhes, ou começar um pedido novo do zero.

Quando um pedido é recebido, os produtos dele entram automaticamente no estoque, sem precisar lançar item por item de novo em outro lugar. Essa tela existe só para quem administra o negócio e foi construída junto com uma empresa real de tecnologia para organizar toda a relação de compra com fornecedores num fluxo só.
