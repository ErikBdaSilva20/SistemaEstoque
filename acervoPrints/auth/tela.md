Essa é a tela onde a pessoa entra no sistema ou cria uma conta nova. Ela reúne, no mesmo espaço, o formulário de entrada e o de cadastro, trocando de um para o outro com uma animação suave, sem recarregar a página.

Pensando em dar liberdade para quem está testando o produto, qualquer conta criada aqui já nasce pronta para usar, com dados de demonstração preenchidos nos bastidores, assim quem assume o papel de administrador já encontra produtos, fornecedores e pedidos de exemplo no sistema.

Depois que o acesso é confirmado, a pessoa é levada direto para o painel principal ou para a tela de venda rápida, dependendo do perfil dela. Esse fluxo foi desenhado para uma empresa real de tecnologia, priorizando simplicidade: poucos campos, uma mensagem clara em caso de erro e nenhuma etapa desnecessária entre o cadastro e o primeiro uso.
