Essa é a tela onde ficam cadastrados os fornecedores da empresa. Nela dá para ver o nome de cada fornecedor, os dados de contato e o prazo médio que ele costuma levar para entregar um pedido depois de confirmado.

A partir daqui, quem administra pode cadastrar um fornecedor novo, atualizar os dados de um já existente ou ajustar o prazo de entrega combinado com ele.

Esse prazo de entrega é usado em outras partes do sistema para ajudar a planejar quando um novo pedido de compra deve ser feito, evitando que o estoque fique zerado enquanto se espera a mercadoria chegar. Essa tela foi criada junto com uma empresa real de tecnologia para manter a relação com fornecedores organizada e fácil de consultar.
